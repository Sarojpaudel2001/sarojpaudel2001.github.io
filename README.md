# Saroj Paudel — SEO Portfolio

A responsive, static SEO portfolio built with HTML, CSS, and JavaScript for free hosting on GitHub Pages.

## Before publishing
- Review all career information for accuracy.
- Replace the placeholder LinkedIn URL in `index.html` with your real LinkedIn profile.
- Review the public email address and remove it if you prefer not to publish it.
- Add only verified results to case studies; planned projects are clearly labeled.

## Publish on GitHub Pages
1. Create a free GitHub account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` to the repository root (not inside a folder).
4. Commit the files.
5. Open **Settings → Pages**.
6. Set **Source** to **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
7. Visit `https://YOUR-USERNAME.github.io` after publication completes.

## Customize
- Edit the text and links in `index.html`.
- Edit fonts, spacing, and colors in `style.css`.
- Add future project case studies only after completing them.
